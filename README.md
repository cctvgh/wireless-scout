# WireScout — 无线勘察与信号覆盖助手

> 大型活动通信保障、网优勘察的"一条龙"本地工具：WiFi 扫描 → 站点/路测导入 → RSRP 分级着色地图 → 勘察报告，全程零第三方依赖、数据不出本机。

## 为什么需要它

做通信保障和网优的同学都熟悉这套流程：现场先扫一遍 WiFi 环境，路测数据躺在手机 APP（网优任我行 / 掌上优）里，基站位置靠记忆和截图，回来还要手工汇总成勘察报告——数据散、工具杂、出报告慢。

WireScout 把这条链收进一个本地 Web 工具，而且**专为内网/防火墙/堡垒机环境设计**：Python 标准库 + 原生 HTML/JS，无任何外部依赖，U 盘拷走即可在任何机器运行。

## 功能亮点

| 能力 | 说明 |
|------|------|
| WiFi 勘察 | 被动读取本机无线网卡可见网络（SSID/BSSID/信号/信道/认证/加密），Windows `netsh` 只读、Linux 回退 `nmcli` |
| 站点导入 | CSV（自动列映射）/ GeoJSON / KML，一键入库 SQLite |
| LTE/NR 路测 | 直接导入网优任我行 / 掌上优等 APP 导出的 RSRP/RSRQ/SINR/PCI/小区数据 |
| 地图可视化 | Leaflet 站点分布地图，RSRP 优/良/弱/差四档分级着色，一眼看清覆盖短板 |
| 基站查询（可选） | OpenCellID 公开接口查询周边基站；API Key 仅环境变量读取，不硬编码 |
| 勘察报告 | AP 数量、加密分布、信道占用、信号质量、RSRP 分级分布一键汇总 |
| 数据导出 | GeoJSON / CSV 全字段导出，可对接规划工具与仿真平台 |

## 快速开始

```bash
git clone https://github.com/wireless-scout.git
cd wireless-scout
python server.py --port 8090
# 浏览器打开 http://127.0.0.1:8090
```

四个页签：WiFi 勘察 / 站点地图 / 遥测导入 / 勘察报告。

> 云电脑/虚拟机通常没有实体无线网卡（WiFi 列表为空属正常）。推荐分工：带无线网卡的笔记本现场采集 → 数据文件传回办公机汇总出报告。

## 作为 TeleAgent 技能使用

本工具同时发布为「星辰超级智能体（TeleAgent）」技能 **`wireless-scout`（无线勘察与信号覆盖助手）**，在技能市场安装后直接对智能体说"无线勘察""导入路测数据""生成勘察报告"即可。
